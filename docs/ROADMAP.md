# Roadmap

The order of work. Each stage is scoped by its own brief, and later stages will change as the game evolves.

| Stage | Outcome | Done when |
|---|---|---|
| S1 Preserve 2019 | The original is safe and clearly labelled | The old code is one click away |
| S2 Foundation | The squad test in a real project | It plays from a public URL, with tests and the bot in CI |
| S3 Public slice, v0.5 | World foundation with zones, gates, pathfinding and saves. Then a town with NPCs, shops, items and arts. Then a first region: three zones, a dungeon and its boss, and first quests | Playtesters finish it unprompted |
| S4 Full systems | Remaining classes, Family House, stances, chips | Any party of three is viable |
| S5 The look | Art direction, asset source, performance budget, and the region reworked | It looks like the target, and runs smoothly on an ordinary laptop |
| S6 The frontier | More cities, zones, dungeons and quests | The bot finishes a full run |
| S7 Release, v1.0 | Public page, README, tag | First-time players finish, and it runs smoothly on an ordinary laptop |
