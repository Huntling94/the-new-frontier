# Roadmap

The order of work. Each stage is scoped by its own brief.

| Stage | Outcome | Done when |
|---|---|---|
| S1 Preserve 2019 | The original is safe and clearly labelled | The old code is one click away |
| S2 Foundation | The squad test in a real project | It plays from a public URL, with tests and the bot in CI |
| S3 Public slice, v0.5 | First region: a city, three areas, a dungeon and its boss | Playtesters finish it unprompted |
| S4 Full systems | Remaining classes, Family House, stances, chips, saves | Any party of three is viable |
| S5 Campaign | All areas and bosses, and the ending | The bot finishes a full run |
| S6 Release, v1.0 | Public page, README, tag | First-time players finish, and it runs smoothly on an ordinary laptop |
